= TEA Pattern Architecture (Vue 3 + Bun)
:toc:

== Overview

`befunge93-vault-cracker` implements **The Elm Architecture (TEA)** as a pure, total JavaScript reducer in `src/engine/game-state.js` paired with a single thin Vue 3 composable (`src/composables/useVaultGame.js`) and six `<script setup>` Single-File Components (`src/components/*.vue`).

== Core Dataflow (`Model -> Message -> Model`)

=== Immutable Model (`createInitialModel`)

`createInitialModel()` returns a plain immutable state snapshot (`tab`, `running`, `completed`, `tempo`, `stage`, `ip`, `dir`, `stack`, `output`, `passcodeInput`, `passcodeStatus`, `attempts`, `matchedPrefixDigits`, `selectedCell`, `visitedKeys`, `selfChecksPassed`, `selfCheckReport`, `log`) with 5 structural and VM equivalence invariants verified immediately at boot.

=== Pure Reducer (`update(state, msg)`)

Every UI event dispatches a plain message object (`SetTab`, `Start`, `Pause`, `Reset`, `SetTempo`, `Tick`, `Step`, `SelectCell`, `InputPasscode`, `SubmitPasscode`, `RunSelfCheck`) into `update(state, msg)`:

* Zero timers, network requests, or DOM mutations occur inside `update`.
* Unknown or out-of-range messages return `state` unchanged by reference.
* Stage 18 marks `completed: true` and `running: false` atomically on the 18th transition.

=== Controlled Effect Boundary (`useVaultGame` & `useVaultTelemetry`)

* `useVaultGame.js` holds `shallowRef(createInitialModel())` and attaches an interval timer **only** while `state.running === true`, cleaning up via `onScopeDispose`.
* `useVaultTelemetry.js` isolates optional Option-2 `marid` network effects (unary I-JSON + RFC 9457 Problem Details + W3C SSE) outside the pure game reducer so offline/static play remains 100% self-contained.
