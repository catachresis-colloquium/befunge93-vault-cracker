== Why Naive AI Workflows Create Mess — and What Changes Here

Unconstrained code generation optimizes locally for *"does the prompt appear satisfied?"* rather than globally for *"is every line load-bearing?"*. Left unchecked across multiple iterations, three failure modes dominate:

1. **Additive Accretion Without Subtraction** — New layers (UI migrations, FFI scaffolds, wire protocols) are added beside dead predecessors instead of replacing them cleanly.
2. **Dual Sources of Truth** — Hardcoded lookup tables or duplicate bundlers are pasted to make an animation or dev server work quickly while leaving the real interpreter or build script disconnected.
3. **Unfalsifiable Claims** — Cleanup or optimization PRs cite line deletions without proving behavioural equivalence or honest latency distributions (`p50`/`p95`).

=== The Four-Rule Discipline Applied in This Audit

[cols="1,3,3", options="header"]
|===
| Rule | Operational Constraint | Failure Mode Prevented

| **1. Saturate Before Touching Code (`S0`)**
| Expand unit, DOM, E2E, contract, and `>= 1,000`-case property suites + deterministic microbenchmarks on *unmodified* code first.
| Prevents silent regressions and exposes latent bugs hidden by shallow happy-path tests.

| **2. Atomic Remediation Stages (`S1`..`Sn`)**
| Group fixes by structural layer (docs/templates -> reactive UI/wire -> engine/bundler -> native FFI). Never mix unrelated refactors.
| Makes every LoC, bundle-byte, and latency shift attributable to a single causal change.

| **3. Retest & Rebench Every Stage**
| Run all parallel contract gates, all target JS runtimes, and all native/JS benchmarks at the end of *each* stage.
| Catches cross-layer interactions (e.g., parallel build races, binary grep probes) immediately.

| **4. Mechanistic Benchmark Honesty**
| Report `ops/s`, `p50`, and `p95` across all stages; explain step-function speedups mechanistically (`pons-asinorum` `implausible-speedup-claim` guard) and report flat curves honestly.
| Eliminates cherry-picked numbers and builds credibility with staff engineers.
|===

== Catalogue of Remediated Findings

Group every finding by `pons-asinorum` tier so reviewers can distinguish objective AST bugs from architectural debt:

* **Tier 0 (Tree-sitter Syntactic Rules)** — Unconditional syntax anti-patterns (`string-concat-in-loop`, `empty-catch-block`, `self-comparison`, `duplicate-branch-body`). Document explicit counter-conditions when a syntactic match is an intentional streaming buffer. All Tier 0 matches eliminated by S3; no false positives retained.
* **Tier 1 (Dataflow & Lifetimes)** — Dead stores, unread struct fields across functions, frozen reactive `computed(() => scalar)` wrappers, and stream double-consumption (`Response.json()` followed by `Response.text()`). All Tier 1 findings remediated by S4; `MaridWireClient` Fetch double-read bug (`P-15`) fixed.
* **Tier 2 (Semantic & Doc Contradictions)** — Stale architecture diagrams, wrong licenses or language stacks in citations, proof comments asserting the wrong theorem, and unrendered template residue. Stale `.a2ml`/`.claude/CLAUDE.md` CSA003 alerts silenced in `.hypatia-ignore`; ROADMAP/CHANGELOG coupled to v0.4.0.
* **Architectural Cohesion** — Disconnected interpreters/FFI libraries, duplicate bundlers, and dead component props/exports. Fake C-ABI template filler removed; Zig C-ABI wired to real `bun:ffi` bridge; 7 zero-caller exports pruned.

== Adopting This Protocol in Another Repository

1. **Run `pons-asinorum` Tier 0/1/2 + dead-export inventory** to enumerate every candidate smell with file:line citations and explicit false-positive counter-conditions.
2. **Author `S0` saturation tests and benchmarks** until every opcode, state transition, wire error path, and invariant has deterministic assertions, then freeze `S0` in an append-only JSONL ledger.
3. **Execute 3–5 single-layer stages**, running the automated measurement script at the end of every stage and refusing to weaken any `must` contractile probe to make a stage pass.
4. **Publish the instantiated report** alongside the code diff so reviewers can audit every claim in under five minutes.
