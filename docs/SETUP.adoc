== Quick Start

[source,bash]
----
./launcher.sh --setup
./launcher.sh --doctor
./launcher.sh --start
----

Then open `http://127.0.0.1:8000` in your browser, or run `just serve` in the foreground.

== Toolchain

`mise.toml` + `mise.lock` provision the pinned developer toolchain:

* *Bun* (`1.2.21+` / `1.4.2` in `mise.lock`) — Tier-1 JavaScript runtime, Vue 3 SFC bundler, `bun:ffi` Zig bridge, HTTP server, and test runner.
* *Deno* (`2.7+` / `2.9.6`) & *pnpm* (`10.28+`) — Secondary JS lockfile & runtime verification per `LANGUAGE-POLICY.adoc` §1.4.
* *Zig* (`0.15.2+` / `0.16.0` in `mise.lock`) — Compiles and tests the native C-ABI Befunge-93 vault FFI (`ffi/zig/` -> `_build/ffi/`).
* *just* (`>= 1.42.0`) — Parallel task runner (`just check`, `just serve`, `just bench`).
* *shellcheck* & *trivy* — Shell script linting and supply-chain vulnerability auditing.
* *Idris2* (via `pack`) — Optional formal verification of `src/abi/*.idr`.
