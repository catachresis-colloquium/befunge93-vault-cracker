= Self-Validating Components (`.machine_readable/svc/k9/`)

This directory holds K9 Contract Specification v1.0.0 self-validating service
components for `befunge93-vault-cracker`:

* `vault-cracker-svc.k9.ncl` — Instantiated Yard-level service configuration
  validated by `scripts/k9/tools/k9-validate.sh`.
* `template-kennel.k9.ncl.in`, `template-yard.k9.ncl.in`, `template-hunt.k9.ncl.in` —
  Parameterized K9 security-leash reference templates (`.in` suffix marks
  uninstantiated templates per `MIGRATION-1058.adoc`).

Validate all K9 components with:

----
