== Overview

`befunge93-vault-cracker` is governed by transparent, verifiable engineering rules enforced both socially by maintainers and mechanically by `coordination.k9`, `.machine_readable/contractiles/must/must.k9.ncl`, and `just check`.

== Roles and Responsibilities

=== Maintainers

Maintainers (listed in link:MAINTAINERS.adoc[`MAINTAINERS.adoc`]) are responsible for:

* Reviewing and squash-merging signed pull requests once all 16 `just check` gates pass.
* Managing semantic releases (`package.json`, `befunge93-vault-cracker_chora.deed`, `ffi/zig/src/main.zig`, `CHANGELOG.adoc`).
* Preserving contractile invariants in `.machine_readable/contractiles/` without silent probe weakening.
* Triaging issues and coordinated security advisories per link:SECURITY.adoc[`SECURITY.adoc`].

=== Contributors

Contributors are expected to:

* Follow link:CODE_OF_CONDUCT.adoc[`CODE_OF_CONDUCT.adoc`] and link:.github/CONTRIBUTING.md[`.github/CONTRIBUTING.md`].
* Accompany behavioural changes with deterministic unit, DOM, property, or R10 contract tests.
* Keep documentation (`README.adoc`, `EXPLAINME.adoc`, `TEST-NEEDS.adoc`) in lockstep with code.

== Decision Making

* *Minor changes* (bug fixes, test saturation, documentation corrections) may be merged by any maintainer once CI passes.
* *Major changes* (new wire routes, ABI/FFI symbol changes, new dependencies across `bun.lock`/`deno.lock`/`pnpm-lock.yaml`) require issue or PR review and updated contracts (`src/abi/Foreign.idr`, `contracts/marid-vault-trial.json`).
* *Contractile amendments* (modifying or retiring a blocking invariant in `must/must.k9.ncl` or `trust/trust.k9.ncl`) require explicit maintainer sign-off and a documented rationale.
