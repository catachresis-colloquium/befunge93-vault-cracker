= Security Policy
:toc:

We take security seriously and appreciate coordinated vulnerability disclosure.

== Reporting a Vulnerability

=== Preferred Method: GitHub Security Advisories

Report vulnerabilities privately through GitHub Security Advisories:

. Navigate to https://github.com/catachresis-colloquium/befunge93-vault-cracker/security/advisories/new[Report a Vulnerability]
. Complete the advisory form with reproduction steps and impact details
. Submit for private triage

=== Alternative: Email

If GitHub Security Advisories are unavailable, contact the maintainers at
`j.d.a.jewell@open.ac.uk` or `6759885+hyperpolymath@users.noreply.github.com`.
Public OpenPGP keys are published at `https://github.com/hyperpolymath.gpg`.

[IMPORTANT]
====
Do not report security vulnerabilities through public GitHub issues, pull requests,
or discussions.
====

== Response Timeline

[cols="1,1,2",options="header"]
|===
|Stage |Target |Description
|Initial Response |48 hours |Acknowledgement of receipt
|Triage |7 days |Severity assessment and remediation plan
|Resolution |90 days |Fix verification, release, and coordinated disclosure
|===

== Scope

* All code, Vue 3 UI components, Bun HTTP server (`server.js`), Zig FFI (`ffi/zig/`),
  Idris2 ABI (`src/abi/`), launcher (`launcher.sh`), and CI workflows in
  `catachresis-colloquium/befunge93-vault-cracker`.
* Runtime security headers (`Content-Security-Policy`, `X-Content-Type-Options`,
  `Cross-Origin-Opener-Policy`, `Referrer-Policy`) and XDG `0700` state isolation.
