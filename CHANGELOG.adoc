= Changelog

All notable changes to `befunge93-vault-cracker` are documented in this file.

== [0.2.0] - 2026-10-24

=== Changed

* Migrated UI from disguised React JSX (`src/Bf93-vault-cracker.res`) to six accessible Vue 3 Single-File Components (`src/App.vue`, `src/components/*.vue`) compiled via `vue/compiler-sfc` on Bun.
* Unified client bundling in `scripts/build.js` (`compileClientJavaScript`) with `mtimeMs` freshness reuse in `server.js`, cutting prebuilt server startup median latency from `23.95 ms` to `0.36 ms`.
* Derived `WALK_TRACE` directly from live `createVmState` + `stepVm` execution (`src/engine/befunge93.js`), eliminating duplicate hardcoded trace literals, and bounded `state.log` (`MAX_LOG_ENTRIES = 200`) in `src/engine/game-state.js`.
* Migrated metadata to formal DEED v1.2.0 (`befunge93-vault-cracker_chora.deed`, `.machine_readable/0-AI-MANIFEST.deed`, `.machine_readable/descriptiles/*.deed`), `coordination.k9` v1.2.0, and K9 v1.0.0 contractiles; retired all `.a2ml` files.
* Overhauled `Justfile` into a 16-gate `[parallel]` system & game-bit verification suite (`just check`, `just test-runtimes`, `just bench`).

=== Added

* Option-2 `metadatastician/marid` companion seam (`src/marid/`, `TelemetryPanel.vue`, `contracts/marid-vault-trial.json`, `docs/MARID-TRIAL-CONTRACT.adoc`) speaking Stage A unary I-JSON + RFC 9457 Problem Details and Stage B W3C SSE with `marid.sync.resync_required`.
* Live `bun:ffi` Zig C-ABI oracle bridge (`src/marid/native-oracle.js` -> `_build/ffi/lib/libbefunge93_vault_cracker.so`) exporting both `befunge93_vault_cracker_run_vault` and full 26-opcode `befunge93_vault_cracker_eval_grid`, cross-verifying all three selectable 10x10 vault levels (`vault-alpha`, `torus-wrap`, `self-mod-cipher` with runtime `g`/`p` patching) and 1,000 random differential fuzz grids against the JS VM, plus multi-stage Zig + Bun `Containerfile`.
* Compliant `launcher.sh` (`launcher-standard_praxis.deed` v0.6.0), full Provisioning Set (`mise.toml`, `mise.lock`, `guix.scm`, `manifest.scm`, `channels.scm`), strict `style-src 'self'` CSP (zero inline `style=` attributes across all Vue SFCs), and RFC 9116 `/.well-known/security.txt` HTTP route.
* Saturated `ProvenTests` verification & benchmark suite (`44` tests, `281,044` assertions across Bun, Deno, and pnpm; `7` JS + native Zig benchmarks with `475 ns/op` `ReleaseFast` Zig C-ABI execution) and reusable AI engineering hygiene report (`docs/reports/ai-engineering-hygiene-2026-10-23.adoc`, `docs/templates/ai-hygiene-report-template.adoc`).

=== Fixed

* Remediated all 18 `pons-asinorum` and architectural findings (`P-01`..`P-15`) and all 7 zero-caller exports, including the `MaridWireClient` Fetch stream double-read bug on non-JSON `5xx` responses (`P-15`), broken `TelemetryPanel.vue` CSS tokens, WAI-ARIA `grid > row > gridcell` roving focus, fake C-ABI template filler in `ffi/zig/`, and stale pre-migration docs.
