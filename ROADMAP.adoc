== Current Status (`v0.4.1`)

* [x] Deterministic 10x10 2D torus Befunge-93 virtual machine (`src/engine/befunge93.js`)
* [x] Pure functional TEA game reducer & boot invariant self-checks (`src/engine/game-state.js`)
* [x] Accessible Vue 3 SFC UI + Bun HTTP server (`src/components/*.vue`, `server.js`)
* [x] DEED v1.2.0, `coordination.k9` v1.2.0, K9 v1.0.0 contractiles, and v0.6.0 `launcher.sh`
* [x] Idris2 `%default total` ABI + native Zig C-ABI vault oracle (`src/abi/`, `ffi/zig/`)
* [x] Option-2 `metadatastician/marid` companion wire seam (Stage A unary/RFC 9457 + Stage B SSE)
* [x] Live `metadatastician/marid` upstream conformance harness (12-case matrix: Stage A unary/RFC 9457, Stage B SSE replay/resync, O-1 Zig C-ABI oracle across all VAULT_LEVELS)
* [x] Custom Vault Workshop: user-editable 10x10 vault grids with bounded step-budget verification
* [x] Shareable deterministic seed challenges (RFC 8785 JCS + base64url challenge descriptors)
* [x] Workshop authoring grid actually rendered and reachable in the browser (`WorkshopGrid.vue` wired into `WorkshopPanel.vue`; was orphaned dead code in `v0.4.0`)
* [x] Full printable-ASCII (`0x20..0x7E`) playfield alphabet so all three shipped levels — incl. `g`/`p` self-modification and decorative data glyphs — are loadable and editable in the Workshop
* [x] Observable Workshop mutation rejections (`workshop.lastError` + `role="alert"`) instead of silently discarded edits
* [x] `sfc.compileAllComponents` benchmark covers all 9 shipped SFCs, and `workshop.validateCustomGrid` / `workshop.deriveTrace` benchmarks with p95 budgets
