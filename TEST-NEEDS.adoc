== Overview

Testing and benchmarking in `befunge93-vault-cracker` align with `hyperpolymath/proven-tests-and-benches` and `hyperpolymath/standards/3-practice/testing-and-benchmarking/TESTING-TAXONOMY.adoc` (18 `TestCategory` axes x 14 `TestAspect` dimensions, Rule R10 runtime-constructed negative fixtures, and >=1,000 generative cases per property).

Run the entire system and game-bit suite concurrently via:

[source,bash]
----
just check
----
