= Befunge-93 Vault Cracker ABI & FFI Documentation
:toc:

== Overview

`befunge93-vault-cracker` implements the estate's *Idris2 ABI + Zig C-ABI FFI* architecture:

* *Formal ABI (`src/abi/`)* — Total Idris2 definitions (`%default total`) specifying bounded
  `Fin 10` torus coordinates, `Direction`, `VaultStage`, memory layout preconditions, and
  `ProvenTests` 18-category by 14-aspect taxonomy obligations.
* *Native FFI (`ffi/zig/`)* — Memory-safe C-ABI implementation in Zig (`src/main.zig`) with
  C header `ffi/zig/include/befunge93_vault_cracker.h`, integration tests (`test/integration_test.zig`),
  and native microbenchmarks (`bench/bench.zig`).

== Exported C-ABI Surface

[source,c]
----
#include "befunge93_vault_cracker.h"

int main(void) {
    befunge93_vault_cracker_handle_t *h = befunge93_vault_cracker_init();
    if (!h) return 1;

    uint8_t passcode[16];
    uint32_t len = 0;
    if (befunge93_vault_cracker_run_vault(h, passcode, sizeof(passcode), &len) == 0) {
        /* passcode[0..8] == "98261047" */
    }

    befunge93_vault_cracker_free(h);
    return 0;
}
----

== Build, Test, Runtime Bridge & Benchmark

[source,bash]
----
just build-ffi            # Compile _build/ffi/lib/libbefunge93_vault_cracker.so (keeping ffi/zig/ pure source)
just check-ffi            # Run Zig unit + C-ABI integration tests in isolated prefix
cd ffi/zig && zig build bench   # Run 50,000-iteration native vault crack microbenchmark
----

At runtime on Bun, link:src/marid/native-oracle.js[`src/marid/native-oracle.js`] loads `_build/ffi/lib/libbefunge93_vault_cracker.so` via `bun:ffi` (`dlopen`), cross-verifies both `befunge93_vault_cracker_run_vault` and arbitrary 10x10 grids (`befunge93_vault_cracker_eval_grid`, including runtime `g`/`p` self-modification) against the JS VM, and surfaces `{ available, engine: "zig-c-abi", agreesWithJsVm }` on `GET /api/marid/capabilities` and `POST /api/vault/runs`.
