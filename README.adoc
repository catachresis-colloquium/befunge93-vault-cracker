**An interactive esoteric-programming puzzle pairing a deterministic 2D Befunge-93 torus virtual machine with a satirical Vue 3 + Bun cryptographic vault UI.**

== Overview

*Befunge-93 Vault Cracker* pits an absurdly overengineered cryptographic vault stack (Ed448, SHAKE3-256, BLAKE3, Kyber-1024, Argon2id, MFA) against Chris Pressey's 1993 two-dimensional esoteric language https://esolangs.org/wiki/Befunge[Befunge-93].

Unlike purely decorative mockups, every cell on the 10x10 torus playfield executes on a real, deterministic Befunge-93 virtual machine (`src/engine/befunge93.js` and `ffi/zig/src/main.zig`) governed by a pure functional TEA (The Elm Architecture) state reducer (`src/engine/game-state.js`) and rendered via accessible Vue 3 Single-File Components (`src/App.vue`, `src/components/*.vue`) on Bun.

=== Highlights

* *Real 2D Torus Befunge-93 VM & Selectable Multi-Level Puzzles* — Cardinal pointer routing (`>`, `<`, `^`, `v`), branches (`_`, `|`), bridge (`#`), ASCII string mode (`"`), stack arithmetic, self-modifying `g`/`p` memory, and bounded termination across three 10x10 vault puzzles (`vault-alpha`, `torus-wrap`, and `self-mod-cipher`).
* *Vue 3 Single-File Components on Bun* — Compiled natively via `scripts/vue-sfc-plugin.js` (`vue/compiler-sfc`) with zero inline styles and served under a strict `style-src 'self'` `Content-Security-Policy` by `server.js`.
* *Pure TEA Game Reducer* — Deterministic `Model -> Message -> Model` transitions with zero idle timers, boot self-checks, tempo controls (`crawling`, `brisk`, `ludicrous`), cell opcode inspection, bounded rolling trace log (`MAX_LOG_ENTRIES = 200`), and leading-digit passcode prefix feedback.
* *Idris2 Formal ABI + Differential Zig C-ABI VM* — Total `Fin 10` torus types and `ProvenTests` 18-category by 14-aspect taxonomy obligations in `src/abi/*.idr`, paired with a full 26-opcode native Zig C-ABI VM (`befunge93_vault_cracker_eval_grid` in `ffi/zig/`) differential-fuzzed across `1,000` random 10x10 grids via `bun:ffi` (`src/marid/native-oracle.js`).
* *Compliant v0.6.0 Launcher & Parallel `Justfile`* — Full lifecycle launcher (`./launcher.sh`) and parallel verification (`just check`) testing both the repository as a system and the game UI bit by bit.

== Quick Start

[source,bash]
----
git clone https://github.com/catachresis-colloquium/befunge93-vault-cracker
cd befunge93-vault-cracker

# Provision tools / verify environment and start in browser
./launcher.sh --doctor
just serve
----

Open `http://127.0.0.1:8000` in your browser (or run `./launcher.sh --start` for background XDG-managed execution).

just check-marid-seam # Verify Option-2 Marid wire contract (Stage A unary/RFC 9457 + Stage B SSE)
just test-runtimes    # Run full test suite across Bun, Deno, and pnpm
just bench            # Run JS/Vue and native Zig C-ABI microbenchmarks

== Optional `marid` Companion Trial

`befunge93-vault-cracker` runs standalone in the browser or on Bun, and also ships a drop-in
wire seam (`src/marid/`, `TelemetryPanel.vue`, `contracts/marid-vault-trial.json`) for
progressive-enhancement integration trials with `metadatastician/marid`. See
link:docs/MARID-TRIAL-CONTRACT.adoc[`docs/MARID-TRIAL-CONTRACT.adoc`] and run
`just serve-marid http://127.0.0.1:6274` to bridge a live Julia `Marid` companion.
