== Claim 1: "Real 2D Torus Befunge-93 VM (JS + Native Zig C-ABI)"

How this is implemented::
* link:src/engine/befunge93.js[`src/engine/befunge93.js`] implements `parseGrid`, `createVmState`, `stepVm`, `executeProgram`, and `deriveWalkTrace` across the 10x10 vault torus (`GRID`).
* Row 0 (`0"7401"v  `) pushes sentinel `0` and ASCII `'7','4','0','1'`; Row 1 (`v"9826"< \`) reverses leftward to push `'6','2','8','9'`; Rows 2–4 drain the stack via `:`, `_`, `,`, and `$` before descending the east shaft `(4,9)..(9,9)` to halt on `@` and emit `98261047` (`EXPECTED_PASSCODE`) with an empty stack.
* `WALK_TRACE` is derived directly at module initialization by stepping `createVmState(GRID)` through `stepVm` — never from a hand-typed trace array.
* link:ffi/zig/src/main.zig[`ffi/zig/src/main.zig`] implements the full 26-opcode native Zig C-ABI VM (`befunge93_vault_cracker_eval_grid` + `befunge93_vault_cracker_run_vault`) loaded live via `bun:ffi` in link:src/marid/native-oracle.js[`src/marid/native-oracle.js`] and differential-fuzzed across `1,000` random 10x10 grids in `tests/property/befunge93-properties.test.js`.

Caveat::
No real cryptographic primitives (Ed448, SHAKE3-256, BLAKE3, Kyber-1024, Argon2id) are attacked; the "vault stack" remains satirical puzzle framing around genuine 2D Befunge-93 execution.
